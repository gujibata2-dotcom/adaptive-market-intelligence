# Adaptive Market Intelligence

Research BTC market hypotheses with reproducible, time-ordered validation.
**PROVE BEFORE TRADE — TRUTH BEFORE BELIEF.**

## Setup

Use Python 3.11 or 3.12 from the repository root:

```sh
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

## Open the dashboard / เปิดหน้าจอใช้งาน

**Windows:** install Python 3.11 or 3.12 with “Add Python to PATH”, download
this repository as a ZIP, extract it, then double-click `start_windows.bat`.
The first launch installs dependencies and opens the browser automatically.

Or run from the repository root after setup:

```sh
python -m streamlit run streamlit_app.py
```

Open `http://localhost:8501` if the browser does not open. Choose a source and
click **เริ่มวิเคราะห์**. Demo mode uses clearly labeled synthetic data and
works offline after installation. Live BTC mode uses Yahoo Finance and drops
the current UTC daily candle. CSV mode requires consecutive daily observations
with `Date,Close,High,Low,Volume` and at least 180 rows. Invalid prices,
duplicate dates, gaps, and nonnumeric values are rejected with a visible error.
Download the holdout prediction ledger from the results screen.

The dashboard compares XGBoost with a training-majority baseline. It shows
historical holdout performance, not a forecast for tomorrow or a trading order.
Switching sources clears old results. Model probabilities are not calibrated.

For browser access without installing Python, deploy on Streamlit Community
Cloud: connect this GitHub repository, select the branch containing these
changes, and set the entrypoint to `streamlit_app.py`. No API key is needed.
This repository does not deploy itself when a PR is opened.

## Run

```sh
python -m app.main
python experiments/h005_price_range_market_regime.py
```

Live runs require Yahoo Finance access. Tests use deterministic local data and
make no market-data requests. H005 paths now work locally and in Colab.

- Classifier: chronological 70/30 split, one purged boundary observation,
  training-majority accuracy baseline, `prediction_ledger_v1_1.csv` output.
- H005: next seven returns form the volatility target; regime thresholds use
  only earlier history. Training ends seven observations before the holdout.
  OLS uses HAC(7); frozen training models predict the holdout without refitting.
- H005 writes `experiments/h005_dataset.csv`, `h005_results.csv` (training
  coefficients/p-values), and `h005_validation.csv` (holdout R², RMSE, and
  training-mean baseline RMSE). A regime absent from training produces an
  explicit error instead of an unsupported prediction.

## Interpreting existing evidence

Committed CSVs and the hypothesis ledger are historical results from the old
methodology, **not results regenerated by this update**. Rerun experiments
before relying on their claims. H006/H007 ledger entries currently have no
reproducible experiment scripts in this repository.

Small p-values show association under a model, not profitable trading. The
classifier evaluates predictions made after each daily close, for the next
close. No transaction costs or executable trading strategy are modeled.
A single holdout does not establish robustness across market periods.
